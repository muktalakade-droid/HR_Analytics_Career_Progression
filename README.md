HR Analytics – Employee Career Progression & Workforce Intelligence

Project Overview

This project focuses on Employee Career Progression, Promotion Gap Analysis, and Workforce Intelligence using Python and Power BI.

The objective is to identify career stagnation patterns, analyze employee promotion gaps, understand workforce trends, and generate actionable HR insights through data analysis and interactive dashboards.

Project Objectives

Analyze employee career progression.

Identify promotion gap patterns.

Calculate career-related metrics.

Explore employee career stagnation risks.

Apply K-Means clustering to identify employee career groups.

Present insights through an interactive Power BI dashboard.

Installation

Install the required Python libraries:

pip install -r requirements.txt

How to Run

Clone or download this repository.

Open the project folder in VS Code.

Install the required dependencies.

Run the dataset inspection script:

python inspect_data.py

Run the career analytics script:

python career_metrics.py

The processed output files will be generated in the Output folder.

Dashboard

The Power BI dashboard presents employee career progression insights, promotion gaps, career stagnation indicators, and workforce intelligence analysis.

Project Outcome

This project demonstrates how data analytics and machine learning techniques can support HR teams in understanding employee career patterns and identifying potential workforce development opportunities.
